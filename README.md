<!-- Plugin description -->
FishReading lets you read books quietly inside IntelliJ IDEA without switching away from your editor.

Core features:
- Import `.epub` and `.txt` books, including many Chinese books with common text encodings.
- Show the current reading text near your editor caret, with keyboard shortcuts for moving forward and backward.
- Choose how much text to show at once, from single-line reading to custom multi-line pages.
- Resume saved progress, switch between books, jump to chapters, or forget books from the IDE Tools menu.
<!-- Plugin description end -->

## Installation

- Using the IDE built-in plugin system:

  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>Marketplace</kbd> > <kbd>Search for "FishReading"</kbd> >
  <kbd>Install</kbd>

- Using JetBrains Marketplace:

  Go to [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32511-fishreading) and install it by clicking the <kbd>Install to ...</kbd> button in case your IDE is running.

  You can also download the [latest release](https://plugins.jetbrains.com/plugin/32511-fishreading/versions) from JetBrains Marketplace and install it manually using
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>

- Manually:

  Download the [latest release](https://plugins.jetbrains.com/plugin/32511-fishreading/releases/latest) and install it manually using
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>
