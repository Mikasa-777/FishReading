# FishReading

<!-- Plugin description -->
FishReading is an IntelliJ IDEA plugin for reading EPUB and TXT books inside the IDE.

Core features:
- Import standard `.epub` and `.txt` books.
- Read line by line with keyboard shortcuts.
- Select chapters and jump through book content quickly.
- Keep reading controls available from the IDE Tools menu.
<!-- Plugin description end -->

## Installation

- Using the IDE built-in plugin system:

  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>Marketplace</kbd> > <kbd>Search for "FishReading"</kbd> >
  <kbd>Install</kbd>
