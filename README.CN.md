FishReading 让你可以在 IntelliJ IDEA 中偷偷地阅读书籍，非常适合上班摸鱼

核心功能：
- 可以导入 `.epub` 和 `.txt` 书籍，包括许多使用常见文本编码的中文书籍。
- 在编辑器光标附近显示当前阅读文本，并支持使用快捷键前进或后退。
- 自定义每次显示的文本量，从单行阅读到多行页面均可配置。
- 从 IDE 的 `工具` 菜单恢复已保存的阅读进度、切换书籍、跳转章节或遗忘书籍。

## 安装

- 使用 IDE 内置插件系统：

  <kbd>设置…</kbd> > <kbd>插件</kbd> > <kbd>Marketplace</kbd> > <kbd>搜索 "FishReading"</kbd> >
  <kbd>安装</kbd>

- 使用 JetBrains Marketplace：

  前往 [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32511-fishreading)。如果你的 IDE 正在运行，可以点击 <kbd>Install to ...</kbd> 按钮进行安装。

  你也可以从 JetBrains Marketplace 下载[最新版本](https://plugins.jetbrains.com/plugin/32511-fishreading/versions)，然后通过
  <kbd>设置…</kbd> > <kbd>插件</kbd> > <kbd>⚙️</kbd> > <kbd>从磁盘安装插件</kbd>
  手动安装。

- 手动安装：

  下载[最新版本](https://plugins.jetbrains.com/plugin/32511-fishreading/releases/latest)，然后通过
  <kbd>设置…</kbd> > <kbd>插件</kbd> > <kbd>⚙️</kbd> > <kbd>从磁盘安装插件</kbd>
  手动安装。
